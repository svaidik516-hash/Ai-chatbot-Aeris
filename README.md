# Ai-chatbot-Aeris
This is a chatbot which works offline and use the llama3 LLM model. Which have a inbuilt plagiarism converter , converts the AI responses to a very simple human language and easily bypasses the plagiarism checkers and AI detectors. 
To use this project on your computer you first have to download the llama3 model from ollama.
To use other function we have to download the python libraries.
